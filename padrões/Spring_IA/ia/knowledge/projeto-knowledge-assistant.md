# Projeto Knowledge Assistant

O Knowledge Assistant é um agente de base de conhecimento desenvolvido na Fatec Professor Jessen Vidal.
O projeto é da disciplina Padrões de Projetos de Sistemas, ministrada pelo professor Giuliano Araújo Bertoti.
A equipe é formada por Giovanna Marques, João Pedro Menegasso, José Wesley e Pedro Henrique Quirino.
O agente recebe a pergunta, planeja, pesquisa nos documentos da pasta knowledge e redige a resposta.
Para ampliar a base de conhecimento, basta adicionar arquivos .md ou .txt na pasta knowledge.
